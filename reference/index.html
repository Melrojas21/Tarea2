    Referencia

    Módulo de cuadratura Gaussiana con polinomios de Legendre.

    Calcula la integral definida de x^6 - x^2 sin(2x) entre 1 y 3 y permite comparar el resultado numérico con el valor exacto para distintos valores de N.

    cuadratura_gaussiana(funcion, limite_inferior, limite_superior, numero_puntos)

    Aproxima la integral de una función en [a, b] con cuadratura Gaussiana.

    Examples:

    >>> round(cuadratura_gaussiana(lambda x: x**2, 0.0, 3.0, 2), 6)
9.0

    gaussxw(numero_puntos)

    Puntos de muestreo y pesos de la cuadratura de Gauss-Legendre.

    Los puntos de muestreo son las raíces del polinomio de Legendre de orden N y están definidos en el intervalo [-1, 1].

    Examples:

    >>> puntos, pesos = gaussxw(2)
>>> puntos.round(6).tolist()
[-0.57735, 0.57735]
>>> pesos.round(6).tolist()
[1.0, 1.0]

    Parameters:

    Name Type Description Default
    numero_puntos int

    Número de puntos de muestreo N.

    		 required

    Returns:

    Name Type Description
    tuple tuple[ndarray, ndarray]

    Arreglos de NumPy (puntos, pesos), ambos de longitud N.

    gaussxwab(limite_inferior, limite_superior, puntos, pesos)

    Escala los puntos y pesos de [-1, 1] al intervalo [a, b].

    Examples:

    >>> puntos, pesos = gaussxw(2)
>>> puntos_ab, pesos_ab = gaussxwab(1.0, 3.0, puntos, pesos)
>>> puntos_ab.round(6).tolist()
[1.42265, 2.57735]
>>> pesos_ab.round(6).tolist()
[1.0, 1.0]

    valor_exacto(limite_inferior, limite_superior)

    Valor analítico de la integral de x^6 - x^2 sin(2x) en [a, b].

    Se evalúa la primitiva F(x) = x^7/7 + x^2 cos(2x)/2 - x sin(2x)/2 - cos(2x)/4 como F(b) - F(a).

    Examples:

    >>> round(valor_exacto(1.0, 3.0), 6)
317.344247
